# Former unversioned Burrau assets

Moved intact into this repository on September 6, 2026, except for regenerable
caches, four LaTeX logs, and one verified duplicate PNG. The retained original
files are checked against the pre-move SHA-256 inventory by `make audit`.

These are historical support materials: arithmetic illustrations, exploratory
continuations, numerical figure generators, and short exposition notes. Use
`../../paper/main.pdf` for the reviewed manuscript and `../../docs/HANDOFF.md`
to resume research. Nothing in this directory is an additional certified result.

The original scripts are preserved verbatim and may contain old machine-local
paths. They are not current build dependencies and should not be run in place:
some overwrite their adjacent data or plots. Copy a selected experiment to
scratch before adapting it. Current reviewed manuscript figures are separately
preserved under `../../paper/figures/`.
